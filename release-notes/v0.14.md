# v0.14 — 桥接协议：Agent 第一次能操作 zeroOS（当前版本）

内核侧实现了 [`agent-bridge-protocol.md`](https://github.com/Holmes-2011/The-Develop-of-zeroOS/blob/main/docs/agent-bridge-protocol.md) v1。
Mac 上的 Agent 程序通过 COM1（115200）和 zeroOS 对话：拿工具清单、调用工具、收事件、提交直觉判断。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 串口接收 | IRQ4 + 环形缓冲区；115200 8N1 |
| ② | 最小 JSON 子集 | 一层对象、字符串 / 整数；就地解析 |
| ③ | 协议 | `hello` / `welcome` / `tools` / `call` / `confirm` / `result` / `event` / `verdict` / `ack` / `error` |
| ④ | 安全边界 | 串口调用走同一个 `tools_invoke()`（`caller=agent`）；**确认框只认物理键盘**；串口开不了开发者模式；`verdict` 只记录不执行 |
| ⑤ | 新工具 / 事件 | `get_intuition`；`intuition`、`protocol error` |
| ⑥ | 测试 | `bridge_test.py` 扮演宿主机走 35 步协议；`test-boot.sh` 自动跑 |

## 测试

| 测试项 | 结果 |
|---|---|
| 协议 35 步 | ✅ 35/35 |
| `pc` 140 项 / `q35` 135 项（含协议阶段） | ✅ |

| 对照实验：串口能答确认框、系统级不弹框、不推事件、转义漏引号、版本不匹配也接受 | ✅ 都被测试抓到 |

## 联调

```bash
cd versions/v0.14-bridge && make
qemu-system-i386 -drive format=raw,file=build/os-image.bin -serial tcp:127.0.0.1:4444,server,nowait
```

宿主机 Agent 连 `127.0.0.1:4444` 发 `{"type":"hello","version":1}` 即可。

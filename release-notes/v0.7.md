# v0.7 — PS/2 键盘：内核第一次能接收输入（当前版本）

在 v0.6.1 基础上新增 **PS/2 键盘驱动（IRQ1）**。在 QEMU 窗口里打字，字符回显到串口，
回车后内核把整行打印出来——这是 v0.8 命令行的雏形，也是以后 Agent 确认框的物理输入来源。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 新增 `keyboard.c` / `keyboard.h` | 扫描码第 1 套 → 美式布局字符；Shift（左右分开记）、Caps Lock、退格、回车；扩展键先忽略 |
| ② | 环形缓冲区 | 中断里只放字符，主循环再取，一写一读不需要加锁 |
| ③ | 行输入 | 最长 79 字符，回车打印 `zeroOS input: ... (ticks=N)` |
| ④ | 无竞争的休眠 | `cli` 检查缓冲区 + `sti; hlt` |
| ⑤ | 去掉每秒一行的 `timer tick` | 会打断输入回显；时钟改由 `ticks=N` 验证 |
| ⑥ | 自动按键测试 | `test-boot.sh` 用 QEMU monitor 的 `sendkey` 打字；GitHub Actions 跑 `pc` 和 `q35` 两种机型 |

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35` 双机型（自动按键） | ✅ 10/10、10/10 |
| 压力测试：连敲 100 个字符 | ✅ 截断为 79 个，下一行正常 |
| 对照实验：不放开 IRQ1 / Shift 失效 | ✅ 测试都能正确报错 |

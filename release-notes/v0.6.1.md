# v0.6.1 — 底层修正：内存上限检查、.bss 清零、自动编译测试（当前版本）

v0.6 的修正版，**运行行为不变**，只修审查中发现的隐患，为后面加键盘、终端、Agent 打地基。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 构建时检查内存上限 | 内核（含 `.bss`）不能长到 `0x7C00`，否则盖掉 GDT；旧检查只看文件大小，查不出 `.bss` 越界 |
| ② | `entry.asm` 清零 `.bss` | 以前只是碰巧落在补零区里 |
| ③ | 中断入口 `cld` | 满足 C 调用约定 |
| ④ | 处理 IRQ7/15 伪中断 | 伪中断不能照常 EOI |
| ⑤ | `KERNEL_SECTORS` 只维护一处 | Makefile 传给 `boot.asm` |
| ⑥ | 构建可移植 | 没有作者本机工具链时自动用系统的 nasm / clang / ld.lld / qemu |
| ⑦ | GitHub Actions 自动编译 + QEMU 启动测试 | 每次推送都跑 |

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35` 双机型 | ✅ 10/10、10/10 |
| tick 频率 | ✅ 10.5 秒 → 10 行 |
| `.bss` 毒化对照实验 | ✅ 修复前 3 字节垃圾值 → 修复后 0 |
| 越界对照实验 | ✅ 24 KB 的 `.bss` 数组被构建拦下（旧版会放行） |

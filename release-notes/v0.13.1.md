# v0.13.1 — 工具层复审修正（当前版本）

v0.13 发布后逐行复审 + 模拟用户 10 轮混合使用，修掉 5 处：

| # | 问题 |
|---|---|
| ① | `inject_fault spin` 不带数字时会读到字符串结尾之后的内存 |
| ② | 故障注入 `demand_touch` 之后 `memtest` 变成 20/22（自检假设按需分页区是干净的） |
| ③ | `demand_touch` 可能和别的使用者碰同一页 |
| ④ | 确认框的说明文字对最长的工具会截断 |
| ⑤ | 倒计时从两位数到一位数时屏幕残留一个字符 |

模拟使用中其他一切正常：0 崩溃、0 泄漏、审计条数和实际调用完全一致、80 次确认框全部按预期。

## 测试

pc 10/10（100 项）、q35 10/10（95 项）、486 / Pentium III / 4MB / 4GB 通过；注入故障后 `memtest` 22/22。

# v0.6 — PIT 定时器：内核第一次收到硬件中断

在 v0.5.1 基础上新增 **PIT 通道 0（100 Hz）**，解除 IRQ0 屏蔽并开中断。
内核主循环每秒往串口打一行 `zeroOS timer tick`。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 新增 `pit.c` / `pit.h` | 通道 0、方式 3、100 Hz；IRQ0 每次触发 tick 加一 |
| ② | `pic_unmask_irq()` | 只放开需要的中断线（本版只放 IRQ0） |
| ③ | `kernel.c` 开中断 | `sti` 之后进入 `hlt` 主循环，每 100 tick 打印一次 |
| ④ | `elf_to_bin.py` | 替代会卡住的 `zig objcopy` |
| ⑤ | `test-boot.sh` | 必须等到 tick 出现才算通过（旧脚本 0.13 秒就结束，测不到时钟） |

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35` 双机型 | ✅ 10/10、10/10 |
| tick 频率 | ✅ 10.5 秒 → 10 行 tick |

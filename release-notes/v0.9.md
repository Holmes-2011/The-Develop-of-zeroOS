# v0.9 — 内存管理：物理页、分页、内核堆

内核搬到 1MB 以上，有了物理页分配、分页和内核堆（`kmalloc` / `kfree`）。
这是 Agent 原型的前置条件：JSON 解析、对话历史都需要动态内存。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 引导扇区重写 | LBA 扩展读盘（不再受 CHS 几何限制）；向 BIOS 要 E820 内存地图；进保护模式后把内核复制到 1MB |
| ② | 内核搬到 1MB | 不再受 0x1000 ~ 0x7C00（约 27KB）的限制；内核有了自己的 GDT 和栈 |
| ③ | 物理页分配 `pmm.c` | 位图管理每一页 4KB，按 E820 地图识别可用内存 |
| ④ | 分页 `paging.c` | 恒等映射可用内存；**第 0 页不映射**，空指针解引用直接报错 |
| ⑤ | 内核堆 `heap.c` | `kmalloc` / `kfree`；按需映射新页；合并相邻空闲块；能发现重复释放 |
| ⑥ | 缺页异常报得更清楚 | 访问的地址、读还是写、是否像空指针 |
| ⑦ | `mem` / `memtest` | `mem` 显示内存地图、空闲页、分页和堆；`memtest` 17 项自检 |
| ⑧ | 禁用 SSE 代码生成 | 编译器曾把循环自动改写成 SSE 指令导致"非法指令"；现在构建时会扫描确认 |

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35` 双机型（31 项检查） | ✅ 10/10、10/10 |
| 内存 4MB ~ 4GB 共 7 种配置 | ✅ 全部通过；可用页数和 BIOS 的 E820 地图逐一对账 |
| 空指针、越界写堆 | ✅ 都被缺页异常准确报出 |
| 大内核跨 4 个读盘块 | ✅ 内存里的内核和文件逐字节一致 |
| 故意改坏分配器 / 去掉 SSE 禁用 | ✅ 测试或构建都能正确报错 |

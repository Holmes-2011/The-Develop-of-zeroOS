# v0.10.1 — 时钟改用 TSC，堆会归还内存（当前版本）

v0.10 的修正版。对 v0.10 做"模拟用户使用"时发现两个问题，这一版修掉。

## 改动

| # | 问题 | 修法 |
|---|---|---|
| ① | 系统时钟在 CPU 忙时变慢（Mac 满载 + zeroOS 满负荷时实测慢 19%） | 改用 CPU 的时间戳计数器（TSC），开机时校准；486 没有 TSC，仍然数中断 |
| ② | 堆只长不缩，跑一次 `bench` 就有约 6MB 一直被占着 | 释放时把堆末尾多余的页还给系统（保留 64KB 余量） |

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35`（45 项检查） | ✅ 10/10、10/10 |
| 486 / Pentium / Pentium III、4MB / 4GB | ✅ 全部通过 |
| Mac 满载 + zeroOS 满负荷时的时钟偏差 | ✅ 新时钟 -0.28%（旧方法 -19.4%） |
| `bench` 后的内存 | ✅ 只少 17 页（以前少 1443 页） |

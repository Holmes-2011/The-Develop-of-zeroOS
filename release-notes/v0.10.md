# v0.10 — 浮点与 SSE2：为本机运行语言模型打基础（当前版本）

开启浮点和 SSE2，补齐推理要用的数学函数，并实测运算速度。
项目决定把自己训练的模型（1B ~ 3B 参数）和 Agent 整个放进 zeroOS 本机运行，
这一版是第一步（路线图见 [Agent 设计文档](https://github.com/Holmes-2011/The-Develop-of-zeroOS/blob/main/docs/agent-design.md)）。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 开启 FPU + SSE2 | CPUID 检测；不支持的 CPU（486、Pentium、Pentium III）照常启动，只是关闭浮点 |
| ② | 数学函数 | `sqrtf` `expf` `logf` `powf` `sinf` `cosf` `tanhf` 等，误差都在 3 个机器精度以内 |
| ③ | `cpu` / `mathtest` / `bench` | CPU 信息；12 项浮点自检；矩阵运算速度 + 1B/3B 模型估算 |
| ④ | 核心代码与浮点代码分开编译 | 中断处理绝不碰 XMM 寄存器，编译器、构建检查、运行时测试三道防线 |
| ⑤ | 核心代码按 486 生成指令 | 修正：v0.6 ~ v0.9 实际要求 Pentium Pro 以上 CPU |

## 实测速度（QEMU，Mac 上软件模拟 x86）

| | 1B 模型 | 3B 模型 |
|---|---|---|
| 8 位量化 | 约 15.5 秒 / 词 | 约 46.6 秒 / 词 |
| 4 位量化 | 约 15.9 秒 / 词 | 约 47.7 秒 / 词 |

真机会快很多倍（未实测）。

| 测试项 | 结果 |
|---|---|

| 486 / Pentium / Pentium III | ✅ 正常启动，浮点自动关闭 |
| 4MB / 4GB 内存 | ✅ |

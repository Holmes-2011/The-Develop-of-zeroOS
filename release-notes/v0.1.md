# v0.1 — 文本模式内核

第一次跑通"引导层 → 保护模式 → C 内核"的完整链路。

## 内容

- `kernel.c`（1259 字节）—— `clear_screen()` + 往 VGA 文本显存 `0xB8000` 写字符

启动后屏幕第 0 行显示：

```
Hello from the C kernel, zeroOS says hi!
```

每个字符占 2 字节：ASCII + 颜色属性 `0x0F`（亮白）。

## 测试结果

| 测试项 | 结果 |
|---|---|
| 连续启动 10 次 | **10 / 10 成功** |
| 屏幕显示 | 完整字符串 ✅ |
| CPU 停止状态 | `EIP` 停在 kmain 的 hlt 循环，`HLT=1` ✅ |
| 稳定性 | 间隔 4 秒两次采样，显存内容完全一致 ✅ |

> 修复了 v0.0.1 的三重故障缺陷之后才通过。

# v0.11 — 硬盘驱动（ATA PIO）+ 块设备接口

硬盘驱动，走轻量路线：块设备接口 + ATA（IDE）PIO 驱动，能从第二块硬盘读取 GB 级的模型权重。
以后的 AHCI（SATA）和 NVMe 驱动挂在同一个接口下面，上层代码不用改。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 块设备接口 | 所有硬盘驱动的统一入口；按以后 DMA 驱动的需要设计 |
| ② | ATA PIO 驱动 | 支持 LBA48（128GB 以上）；每次等待都有超时，没有硬盘的机器不会卡住 |
| ③ | `disks` / `diskread` / `diskcheck` / `diskbench` | 列出硬盘、看扇区内容、校验测试图案、测速度 |
| ④ | 测试硬盘生成器 | 每个扇区都能按扇区号校验；用稀疏文件在 143GB 处写数据测 48 位寻址 |

## 实测

| 项目 | 结果 |
|---|---|
| `pc` / `q35`（57 / 52 项检查） | ✅ 10/10、10/10 |
| 64MB 全盘逐扇区校验 | ✅ 0 错误 |
| 128GB 以外的扇区（48 位寻址） | ✅ 读对 |
| 读盘速度（QEMU） | 约 7–8 MB/s：读 1GB 约 2.5 分钟，3GB 约 7.4 分钟 |
| 对照实验：改坏 1 位、LBA48 写反、拔掉硬盘 | ✅ 都能正确发现或处理 |

## 限制

只支持 ATA/IDE（QEMU 的 `pc` 机型）；`q35` 和现代电脑的 SATA / NVMe 要等以后的驱动。只读。

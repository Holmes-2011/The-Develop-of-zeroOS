# v0.5.1 — 修正 4 处异常的错误码分类

**v0.5 的修正版**：修掉 `isr.asm` 里 17 / 21 / 29 / 30 号异常的错误码分类错误。

## 改动

```diff
-ISR_NOERRCODE 17   ; 对齐检查
+ISR_ERRCODE   17   ; 对齐检查（错误码恒为 0）
-ISR_NOERRCODE 21
+ISR_ERRCODE   21   ; 控制保护 #CP
-ISR_NOERRCODE 29
+ISR_ERRCODE   29   ; VMM 通信 #VC
-ISR_NOERRCODE 30
+ISR_ERRCODE   30   ; 安全异常 #SX
```

**依据**：Intel SDM Vol.3A 6.3.1 / AMD APM Vol.2 8.4.2。
压错误码的向量共 10 个：`8, 10, 11, 12, 13, 14, 17, 21, 29, 30`。
同时在 `isr.asm` 里补了一段注释，把依据和几个易错点写清楚。

## 相对上游 v0.5 的全部差异

| # | 差异 | 说明 |
|---|---|---|
| ① | 上述 4 处错误码分类 | 见上 |
| ② | 引导层补 `cli` | 消除时钟中断导致三重故障的窗口 |
| ③ | 镜像补零到 512 KB | ≤256 KB 的盘会被 AHCI 控制器拒绝启动 |
| ④ | 构建体系改为 macOS 原生 | clang 交叉目标 + Zig 的 LLD；**不需要 Kali 虚拟机** |
| ⑤ | `test-boot.sh` 跨平台 | 上游脚本用了 macOS 上不存在的 `timeout` 和 `qemu-system-i386` |

## 回归测试（确认改动没弄坏任何东西）

| 测试项 | 结果 |
|---|---|
| 反汇编核对 4 个入口桩的压栈指令 | ✅ 4 个只压 1 个 dword，其余保持压 2 个 |
| **32 个异常向量全扫** | ✅ **32 / 32** |
| **真实 #GP 的错误码路径** | ✅ 与修复前**逐位一致** |
| `pc` / `q35` 双机型 | ✅ 都通过 |
| 稳定性（累计启动） | `pc` **45/45**、`q35` **45/45** |

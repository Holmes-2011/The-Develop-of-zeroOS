# v0.8 — 屏幕有字了：内核命令行

在 v0.7 基础上，**屏幕第一次显示文字**，并有了内核命令行。开机后屏幕上只有一句欢迎语和提示符：

```
zeroOS v0.8
Type 'help' for a list of commands.

zeroOS> _
```

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | `vga.c` 屏幕输出 | 80×25 文字模式、16 色、硬件光标、写满自动上滚 |
| ② | `console.c` | 同一份文字同时写屏幕和串口 |
| ③ | `shell.c` 内核命令行 | `help` / `clear` / `echo` / `uptime` / `mem` / `version`；未知命令红字提示 |
| ④ | `mem` | 从 CMOS 读内存大小，列出内核占用的内存范围 |
| ⑤ | 异常显示在屏幕上 | 红字 + 出错地址 EIP |
| ⑥ | 代码整理 | 串口拆到 `serial.c`；Makefile 改用通用规则 |
| ⑦ | 测试直接读显存 | 用 QEMU `pmemsave` 存下 `0xB8000`，核对屏幕上的每一行；CI 加跑 q35 和 128 MB |

命令表是 [系统内置 Agent 设计](https://github.com/Holmes-2011/The-Develop-of-zeroOS/blob/main/docs/agent-design.md) 里"工具登记表"的第一版。

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35` 双机型（22 项检查，含屏幕核对） | ✅ 10/10、10/10 |
| `mem` 在 16 / 64 / 128 MB 下 | ✅ 全部报对 |
| 长命令不折行、异常显示在屏幕上 | ✅ |
| 对照实验：不上滚 / 不写显存 | ✅ 测试都能正确报错；后者只有屏幕检查失败，证明屏幕检查是独立的 |

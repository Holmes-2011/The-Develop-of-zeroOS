# v0.13 — 工具层：权限、确认框、审计

Agent 能对 zeroOS 做的每一件事，都必须先在这里登记成"工具"，并且只能通过这一层来做。
这是权限模型的实现，也是 Agent 接进来之前的最后一块内核基础。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 工具登记表 | 11 个内置工具，4 级权限：只读 / 可撤销 / 破坏性 / 系统级 |
| ② | 权限判定 | 破坏性要确认；系统级默认拒绝、开发者模式下要确认 |
| ③ | 内核绘制的确认框 | 只认物理键盘的 y / n；20 秒超时；弹框前清空键盘缓冲区，提前敲好的 y 作废 |
| ④ | 开发者模式 | 打开本身要过确认框 |
| ⑤ | 审计日志 | 每次调用一条，放行 / 拒绝 / 超时都记 |
| ⑥ | 诊断和故障注入 | `heap_check` / `pmm_check`；`inject_fault`（泄漏、非法释放、缺页、CPU 满载）给系统直觉模型当训练素材 |
| ⑦ | 命令 | `tools` `tool` `devmode` `audit` `sleep` |

人在命令行敲 `tool get_memory`，和以后 Agent 通过串口发来的调用，走同一个入口、同一套判定、同一本账。

## 测试

| 测试项 | 结果 |
|---|---|
| `pc` / `q35`（100 / 95 项检查） | ✅ 10/10、10/10 |
| 486 / Pentium III / 4MB / 4GB | ✅ 全部通过 |
| 对照实验：不清键盘缓冲区、权限表写坏、堆块大小记错、物理页计数漂移 | ✅ 都能被测试或诊断工具抓到 |

## 架构说明

2026-10-18 决定：Agent 和系统直觉模型**不进内核**，先在宿主机上通过串口协议（[`docs/agent-bridge-protocol.md`](https://github.com/Holmes-2011/The-Develop-of-zeroOS/blob/main/docs/agent-bridge-protocol.md)）调用本版的工具层，以后搬进 zeroOS 用户态。内核侧的协议实现是 v0.14。

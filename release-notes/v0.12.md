# v0.12 — 感知层：计数器 + 采样 + 事件日志 + 按需分页（当前版本）

系统内置 Agent 的第一层：让系统"看得见自己"。各子系统把自己的状态报出来，时钟中断里每 100 毫秒采样一次，
重要事件记进日志。以后的系统直觉模块和诊断工具都从这里取数据。

## 改动

| # | 改动 | 说明 |
|---|---|---|
| ① | 计数器 | 中断、键盘、堆、物理页、缺页、CPU 空闲时间，共 18 项 |
| ② | 采样 | 时钟中断里每 100 毫秒一次，长命令运行时也不漏采；环形缓冲区约 25 秒 |
| ③ | 事件日志 | 开机、溢出、非法释放、伪中断、按需缺页……同类事件 1 秒内合并 |
| ④ | 按需分页区 | 那段地址里的缺页现场补一页、继续运行，而不是停机——缺页成了可以观测的信号 |
| ⑤ | `metrics` / `events` / `telstream` | 看计数和速率、看事件、把采样实时输出到串口 |
| ⑥ | 路线图调整 | v0.13 工具层 → v0.14 直觉模块接口；见 `docs/agent-design.md` |

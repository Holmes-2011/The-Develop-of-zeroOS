# v0.3 — IDT 异常处理

新增 **IDT（中断描述符表）**，把 0~31 号 CPU 异常接到自己的处理函数。
以前遇到异常会静默三重故障重启，现在能捕获并报出是哪一种异常。

## 内容

| 文件 | 大小 | 说明 |
|---|---|---|
| `kernel.c` | 4205 | 串口 + 清屏 + 异常名表 + `fault_handler` |
| `idt.c` | 3667 | 256 项 IDT，先全部清零再逐个注册 |
| `idt.h` | 655 | 结构体与声明 |
| `isr.asm` | 2270 | `isr0`~`isr31` 入口桩 + 公共存根 + `idt_flush` |

## 测试结果

| 测试项 | 结果 |
|---|---|
| 启动（3 行串口） | ✅ |
| 异常向量抽查（0 / 3 / 13 / 14） | ✅ 名字全部正确 |
| 机型扫描（8 种 QEMU 机型） | 7 种通过，**`q35` 失败** → 定位到镜像过小问题 |
| 修复后连续启动 | **50 / 50** |

## 这一版发现的另一个缺陷

**21 KB 的镜像被 AHCI 控制器拒绝启动** —— `q35` 及现代真机用的是 SATA/AHCI，
SeaBIOS 按容量推算磁盘几何会失败，于是它认为"这不是一块可启动的盘"，
**连引导扇区都不载入**，表现为静默黑屏、一个报错都没有。

二分定位结果：≤256 KB 必失败，**≥512 KB 起成功**。

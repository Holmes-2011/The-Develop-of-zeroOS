# v0.13.2 — 全量复审修正（当前版本）

对 v0.6 以来的全部内核代码做了一次逐行复审 + 8 组专项压力测试，筛出 14 处问题，这一版全部修掉。
对用户可见的变化只有：新工具 `stack_check`、`inject_fault stack_use`，`mem` 多显示一行栈水位。

## 实测暴露的（压力测试里真的出了错）

| # | 问题 |
|---|---|
| ① | **堆扩张失败会吞掉物理页**。内存紧张时一次失败的大申请能把全部物理页吞光，随后系统停机。2MB 配置跑全套复现 |
| ② | **页表页永不回收**，释放之后账面总少几页 |
| ③ | **Ctrl+C、Ctrl+Z 会打出字符** |
| ④ | **遥测流会和正在敲的命令粘成一行**（v0.14 的串口协议行也会受害，必须先修） |
| ⑫ | `diskcheck` 越界时的提示误导 |
| ⑭ | 新工具 `stack_use` 第一版被编译器优化掉，实际没用到栈 |

## 复审发现的（实测没触发过，但真机上可能触发）

引导扇区不验证 A20；栈溢出无法察觉（新增栈哨兵 + 水位）；分页初始化内存不足不报错；`heap_check` 遇链表成环会死循环；
中断返回前多余的 `sti`；`keyboard_flush` 无条件开中断；`sleep` 不计入空闲时间；`memcpy` 逐字节。

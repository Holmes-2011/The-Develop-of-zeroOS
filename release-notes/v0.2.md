# v0.2 — 串口调试输出

新增 **COM1 串口输出**，让内核的运行进度能在终端里看到，不依赖屏幕。

## 内容

- `kernel.c`（2397 字节）—— 标准 16550 UART 初始化（`0x3F8`，轮询方式）

串口输出：

```
zeroOS kernel v0.2: entered protected mode, kmain() started
zeroOS kernel v0.2: screen cleared, entering halt loop
```

屏幕保持纯黑（`0xB8000` 全是 `0x20 0x00`）。

## 测试结果

编译通过、启动通过、串口两行完整、屏幕确认纯黑。

> ⚠️ 这一版是在测试体系还不完善时测的，**覆盖面比 v0.3 之后的版本窄**：
> 没有多次重复启动数据，也没有机型扫描。如实标注，不编造。

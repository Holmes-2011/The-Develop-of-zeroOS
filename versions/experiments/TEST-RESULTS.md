# experiments — 不属于版本线的独立实验

这里放的是**没进入 zeroOS 版本线**的东西，留作记录。

## `kernel-ring-graphics.c`（2239 字节）

一个**图形模式**实验：把显卡切到 VGA 模式 `0x13`（320×200、256 色），
在屏幕正中画一个白色空心圆环。

和版本线的关系：这是一次**独立尝试**，后来上游明确放弃了图形路线
（v0.3 的 `boot.asm` 里写着"不再切到图形模式画圆环"）。

### 怎么跑

引导层需要先把显卡切到模式 `0x13`（必须在实模式下做，进保护模式就来不及了）：

```asm
mov ax, 0x0013      ; ah=0x00 设置显示模式, al=0x13 → 320x200 256 色
int 0x10
```

这段在 `../experiments/boot-with-vga-mode-toggle.asm` 里是**注释开关**的形式：

```asm
; ---- 显示模式开关 ----
; 默认走 BIOS 文本模式（80x25，显存 0xB8000）
; 跑 kernel-ring-graphics.c 时取消下面两行的注释：
; mov ax, 0x0013
; int 0x10
```

用法：把 `kernel-ring-graphics.c` 复制成工程的 `kernel.c`，
再把引导层里那两行取消注释，`make` 之后启动。

### 测试结果 ✅

| 测试 | 结果 |
|---|---|
| 编译 | ✅ 成功 |
| 启动 | ✅ 成功 |
| 画面 | ✅ 黑底白色空心圆环，居中 |
| 圆环参数核对 | ✅ 与源码里 `draw_ring(160, 100, 30, 4, COLOR_WHITE)` 一致 |

**证据**：`screenshot-ring.png`（本目录）。

### 当时诊断出的一个测试陷阱

第一次读图形显存 `0xA0000` 的前 2000 字节，发现"非黑像素 0 个"，差点误判成没画出来。

实际上**这是对的** —— 圆环在屏幕正中，对应偏移是 `100*320 + 160 = 32160`，
根本不在开头那 2000 字节里。**采样位置选错了，不是程序错了。**

## `boot-with-vga-mode-toggle.asm`（4286 字节）

`kernel-ring-graphics.c` 配套的引导层，和工程现在用的 `boot.asm` 的区别只有一处：

带一个**注释形式**的显示模式开关（默认文本模式，取消注释即切图形模式）。

---

## 和版本线的关系

| | 版本线（v0.1 → v0.5.1） | 这里的实验 |
|---|---|---|
| 显示方式 | BIOS 文本模式（`0xB8000`） | VGA 图形模式 `0x13`（`0xA0000`） |
| 画面 | 纯黑 + 串口调试信息 | 白底圆环 |
| 是否并入主线 | ✅ 是 | ❌ 否，上游明确放弃 |

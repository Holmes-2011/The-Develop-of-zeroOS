# v0.20.1 测试记录

## 本版内容

v0.20 的补丁：**双缓冲合成器**（拖动不闪）和**三重退出**（ESC / q、任务栏 Exit、60 秒空闲自动退出）。

| 改动 | 文件 |
|---|---|
| 后台缓冲（3MB，pmm 分配 + 映射到 0xFE000000）、裁剪、脏区 present | `gfx.c` / `gfx.h` |
| 窗口阴影 / 标题栏渐变 / 关闭按钮 / 任务栏 / 指针前台绘制 | `wm.c` |
| Exit 按钮、q 键、60 秒空闲退出 | `wm.c` |
| 测试断言更新（拖动坐标 190,146、窗口正文像素、Exit 按钮） | `test-boot.sh` |

### 双缓冲验证方式

`scene_rect()` 只在脏区里重画（背景 + 窗口 + 任务栏），`gfx_present()` 把同一块后台拷到前台，
指针单独画在前台。拖动时脏区 = 旧窗口 ∪ 新窗口，一次重绘一次拷贝，不会出现中间帧。

## 已知限制

| 项目 | 说明 |
|---|---|
| 纯软件合成 | 全屏重绘在 TCG 上慢；靠脏区规避 |
| 无动画/圆角 | 只是视觉近似 |
| 3MB 后台缓冲 | 2MB 内存机器降级为直接绘制（有闪烁） |
| 60 秒兜底 | 演示时可能突然退出，可调 |

# v0.8-shell 测试记录

## 本版内容

在 v0.7 基础上，**屏幕第一次显示文字**，并有了内核命令行：

| 改动 | 文件 |
|---|---|
| VGA 文字模式输出：80×25、16 色、硬件光标、`\n` / `\b` / `\t`、写满自动上滚 | `vga.c` / `vga.h`（新增） |
| 控制台：同一份文字同时写屏幕和串口（屏幕给人看，串口给测试看） | `console.c` / `console.h`（新增） |
| 内核命令行：读一行 → 拆命令名和参数 → 查命令表执行；未知命令红字提示 | `shell.c` / `shell.h`（新增） |
| 命令：`help` `clear` `echo` `uptime` `mem` `version` | `shell.c` |
| `mem`：从 CMOS 读内存大小（16MB 以下 / 以上两套寄存器），并列出内核占用范围 | `shell.c` |
| CPU 异常信息同时显示在屏幕上（红字）并带出错地址 EIP | `kernel.c` |
| 串口函数从 `kernel.c` 拆到 `serial.c`；`kernel.c` 只剩中断分发和 `kmain` | `serial.c` / `serial.h`（新增） |
| Makefile：所有 C 文件改用一条通用规则，新增文件只要加进 `C_SRCS` | `Makefile` |

**屏幕上只有欢迎语和命令行**，启动日志仍然只走串口——保持"开机不堆调试信息"的原则。

命令表就是 [`docs/agent-design.md`](../../docs/agent-design.md) 里"工具登记表"的第一版。

## 测试方法

`test-boot.sh` 用 QEMU monitor 的 `sendkey` 依次敲：

```
help / uptime / mem / echo Hi, zerx⌫oOS! / foo / （只有空格的行）/ help / clear
```

然后用 `pmemsave 0xb8000 4000` 把**显存**存下来，还原成 25 行文字，直接核对屏幕内容。
`clear` 之前和之后各存一次。共 **22 项检查**：

| 类别 | 检查内容 |
|---|---|
| 串口：启动 | 5 行启动日志 |
| 串口：命令 | `help` 列出 6 个命令；`uptime` 格式正确且 ticks > 0；`mem` 报的内存 = QEMU 的 `-m`；`mem` 报出内核范围；`echo` 输出 `Hi, zeroOS!`（Shift、符号、空格、退格）；未知命令报错 |
| 屏幕 | 有 `Hi, zeroOS!`；有未知命令提示；写满一屏后最后一行是提示符；欢迎语已滚出屏幕；`clear` 后第一行是提示符、其余 24 行全空 |

## 测试结果

| 测试项 | 结果 |
|---|---|
| `make` | ✅ 无警告；内存占用 `0x1000 ~ 0x35A4`（约 9.6 KB），上限 `0x7C00` |
| `-M pc` 重复 | ✅ **10/10**（每次 22/22） |
| `-M q35` 重复 | ✅ **10/10** |
| 不同内存大小下的 `mem` | ✅ 16 MB → `16384 KB`；64 MB → `65536 KB`；128 MB → `131072 KB`（覆盖 CMOS 两套寄存器） |
| 长命令：`echo` + 90 个字符 | ✅ 屏幕上这一行正好 79 列不折行，输入截断在 71 个字符 |
| 异常路径（取消注释 `int $0x0`） | ✅ 屏幕第 2 行红字 `CPU exception -> Division By Zero at EIP 0x0000131A`，串口同样内容，随后停机 |

### 对照实验：屏幕检查能不能独立抓到故障

| 故意弄坏 | 结果 |
|---|---|
| 不上滚（写到底就回到第 0 行） | ❌ 21/22，报"最后一行是提示符"失败（正确地失败） |
| 不写显存（串口照常） | ❌ 18/22，4 项屏幕检查失败，**串口检查全部通过** —— 说明屏幕检查是独立的，不是在重复检查串口 |

### 复查中修掉的问题

- 最初 `LINE_MAX` 设成 76，但提示符 `zeroOS> ` 占 8 列，8 + 76 超过 80 列，长命令会折到下一行。改为 71 后实测一行正好 79 列。

### 无法在本机实测的部分

| 项目 | 说明 |
|---|---|
| 真机 CMOS 内存值 | QEMU 会如实填写 CMOS；真机 BIOS 填写的值可能不准（这是老接口），v0.9 会改用 BIOS 的 E820 内存表 |
| 真机显卡 | 现代显卡在 BIOS / CSM 下仍兼容 VGA 文字模式；纯 UEFI 启动没有文字模式，届时需要改用帧缓冲 |

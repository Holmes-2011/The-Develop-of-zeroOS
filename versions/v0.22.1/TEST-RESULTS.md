# v0.22.1 测试记录

## 本版内容

拖动顺滑化：拖动开始时预渲染“无窗场景”和“窗口精灵”，移动时只做内存拷贝；
标题文字改为透明背景。

## 测试结果

| 测试项 | 结果 |
|---|---|
| `-M pc` 全套 | ✅ **166/166** |
| 拖动后 `wm: win0=190,146` | ✅ |
| 拖动中截屏检查 | ✅ 无背景残影；标题文字贴合渐变 |
| USB 平板拖动 | ✅ |
| q35 | 未跑（本补丁只改桌面绘制路径） |

### 验证方法

- 桌面 → 标题栏按下 → 移动到 (300,150) → 松开 → `wminfo` 应为 `win0=190,146`。
- 拖动中 `screendump`，检查窗口周围没有捕获时的背景块、旧位置没有残影。

## 实现要点

| 步骤 | 做法 |
|---|---|
| 拖动开始 | `scene_rect_ex(full, exclude=dragged)` 画无窗场景 → `present_all` |
| 精灵 | 窗口临时挪到 (0,0)，画进后台，`gfx_capture` 出 `w×h` |
| 拖动中 | `gfx_present(脏区)` + `gfx_front_fill`（阴影/边框）+ `gfx_front_blit`（精灵）+ 指针 |
| 拖动结束 | `full_redraw()` 恢复完整场景 |

## 已知限制

- 仍是软件合成，无 GPU/vsync/动画。
- 精灵只缓存被拖窗口；其他窗口在拖动期间是静态的（符合预期）。
- 没有做帧率测量，优化属于“去掉每帧重画”的结构性改动。

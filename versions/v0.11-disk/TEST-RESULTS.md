# v0.11-disk 测试记录

## 本版内容

硬盘驱动，走**轻量路线**：块设备接口 + ATA（IDE）PIO 驱动。目的是能从第二块硬盘读取 GB 级的模型权重。
AHCI（SATA）和 NVMe 以后加，挂在同一个块设备接口下面，上层代码不用改。

| 改动 | 文件 |
|---|---|
| **块设备接口**：所有硬盘驱动都实现 `read(扇区号, 扇区数, 缓冲区)`，上层只认它；一次可读很多扇区、缓冲区 4KB 对齐——按以后 DMA 驱动的需要设计 | `blockdev.c` / `blockdev.h`（新增） |
| **ATA PIO 驱动**：探测两个通道的主 / 从盘，IDENTIFY 读型号和容量，支持 LBA28 和 **LBA48**（128GB 以上）；跳过光驱；轮询不用中断，每次等待都有 2 秒超时 | `ata.c` / `ata.h`（新增） |
| 新命令：`disks`、`diskread`、`diskcheck`、`diskbench` | `disktest.c`（新增）、`shell.c` |
| 测试硬盘生成器：每个扇区的内容都能由扇区号算出来，可以写在 128GB 以外（稀疏文件） | `gen_testdisk.py`（新增） |

**只读**：写盘以后再做——写盘属于"破坏性"操作，届时要接上 Agent 设计里的权限检查。

## 测试方法

`test-boot.sh` 生成一块测试硬盘挂成第二块盘：8MB 图案，外加 LBA28 能访问的最后一个扇区（268435455）、
只有 LBA48 才能访问的第一个扇区（268435456）、约 143GB 处的一个扇区（300000000）。
逻辑大小 143GB，实际只占约 9MB。然后逐扇区校验。

## 测试结果

| 测试项 | 结果 |
|---|---|
| `make` | ✅ 无警告；核心代码无浮点 / SSE / cmov |
| `-M pc` 重复 | ✅ **10/10**（每次 57/57） |
| `-M q35` 重复 | ✅ **10/10**（52/52：没有老式 IDE 端口，正常启动并报告"没有 ATA 硬盘"） |
| 486 / Pentium III / 4MB / 4GB（pc）/ 4GB（q35） | ✅ 52/52、52/52、53/53、57/57、52/52 |
| 64MB 全盘校验（131072 个扇区，每次读 1MB） | ✅ 0 个错误 |
| 启动盘第 0 扇区 | ✅ 读出的正是引导代码，结尾 `55 AA` |
| 错误输入：扇区越界、不存在的盘、参数不是数字 | ✅ 都给出提示，不崩溃 |

### 读盘速度（QEMU，Mac 上软件模拟 x86）

| 每次读 | 速度 | 读 1GB | 读 1.5GB | 读 3GB |
|---|---|---|---|---|
| 128KB（256 扇区） | 约 4.1 MB/s | 约 4 分钟 | 约 6 分钟 | 约 12.6 分钟 |
| **1MB（2048 扇区）** | **约 7–8 MB/s** | **约 2.5 分钟** | **约 3.7 分钟** | **约 7.4 分钟** |

PIO 是 CPU 一次搬 2 字节，在模拟器里每次端口读写都要软件模拟，所以慢。以后的 AHCI / NVMe 用 DMA，会快很多。

### 对照实验

| 实验 | 结果 |
|---|---|
| 测试盘第 5000 扇区改掉 1 位 | ✅ `diskcheck: 16384 sectors, 1 bad (first at sector 5000)` |
| 驱动里 LBA48 的寄存器写入顺序写反（先低后高） | ❌ 8MB 校验、交界扇区、143GB 扇区、diskbench 全部失败（正确地失败） |
| 只接启动盘、不接第二块盘 | ✅ 只找到 `ata0`；访问 `ata1` 提示"no such disk"，系统照常运行 |

### 测试中发现并修掉的问题

| 问题 | 处理 |
|---|---|
| `diskbench` 计算 KB/s 用了 64 位除法，核心代码链接不了 | 拆成"整数部分 + 余数部分"，每一步都在 32 位以内 |

### 已知限制

| 项目 | 说明 |
|---|---|
| 只支持 ATA/IDE | q35 机型、现代电脑的 SATA（AHCI 模式）、NVMe、U 盘都找不到——要等以后的驱动 |
| 只读 | 写盘以后做，要过权限检查 |
| 只认硬盘 | 光驱（ATAPI）跳过 |
| 只支持 LBA48 的 QEMU 硬盘做过测试 | 只支持 LBA28 的老硬盘走"每次最多 256 扇区"的分批路径，代码有，但 QEMU 模拟不出这种硬盘，没有实测 |
| `diskcheck` 显示的扇区号是 32 位 | 2TB 以上的位置显示会不对（读本身没问题） |
